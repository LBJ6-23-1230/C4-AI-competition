## 录制前的准备（30 秒自检）

**1. 起后端**（录屏时这个窗口要一直开着）

```powershell
cd ..\03-演示文件与源代码\server\zhixue-agent-server
python run.py
```

看到这两行才算成功：

```
监听地址   : http://0.0.0.0:5000
LLM        : 已配置 DASHSCOPE_API_KEY，走真实大模型
```

**2. 自检大模型可用性**

```powershell
python ..\03-演示文件与源代码\tools\check_llm_ready.ps1
```

> ⚠️ **后端没起**是录视频最常见的一次性失误 —— App 会显示
> 「连接超时或网络不可用，请检查服务地址后重试」。

**3. 确认 App 内接口地址**

| 环境 | baseUrl |
|---|---|
| 模拟器 | `http://10.0.2.2:5000`（默认已对） |
| 真机 | `http://<开发机局域网IP>:5000` |

改法：App 首页 → 右上角「工具」→ **接口环境** → 填地址 → 「应用此地址」

**4. 重置演示数据**（保证基线数字是 `66.67` 那套）

```
POST http://127.0.0.1:5000/api/v1/demo/reset
```

## 录制避坑

- **一句话一条**：不要在一条里塞多个功能，剪辑时不好取舍
- **等回复**：真实大模型单次响应约 **25–30 秒**，别急着切走
- **横屏录制**：平板/2in1 段落建议横屏，展示大屏布局
- **先彩排一遍**：确认没有「连接超时」「降级回复」再正式录
- **分辨率**：建议 1080p 以上，帧率 30fps 足够

## 三、项目是什么

**知学Mate** 是一个基于 HarmonyOS 全场景的**大学生主动助学 Agent**。
它不是"问答机器人"，而是把「**对话** → **诊断** → **计划** → **练习** → **复盘**」
串成闭环的学习秘书。

### 核心设计纪律（本项目最重要的技术主张）

> **大模型只负责「理解意图」与「生成自然语言」；
> 所有业务计算 —— 判分、掌握度、优先级、重规划 —— 一律留在确定性代码里。**

这条纪律带来的可验证结果：同一份输入**永远得到同一个分数**，
不受模型随机性影响。演示基线可复现：

```
错 √√× → score 66.67     全错 → score 0.0
掌握度 42 → 58            计划任务时长 [30,30] → [45,15]
profileVersion [1,2]      planVersion [1,2]
```

### 用到的鸿蒙特性

| 特性 | 落点 |
|---|---|
| 意图框架（小艺） | `insightintent/` 两个意图：查今日计划 / 开始专注 |
| 服务卡片 | `widget/` 桌面学习卡片 |
| **跨设备分布式** | `DistributedStateService` —— 手机开始专注，平板看到同一任务 |
| 华为账号一键登录 | `HuaweiAccountService`（Account Kit） |
| 多设备形态 | `phone / tablet / 2in1` 三形态声明 + 大屏限宽布局 |

## 四、怎么跑起来

### 后端（Python 3.12 + Flask）

```bash
cd 03-演示文件与源代码/server/zhixue-agent-server
python -m venv .venv && .venv/Scripts/activate      # Windows
pip install -r requirements.txt
cp .env.example .env                                 # 填入 DASHSCOPE_API_KEY（可选）
python run.py
```

> 不配 Key 也能跑：聊天层会**诚实降级**为本地确定性规则，
> 并在回复里明确标注"本次大模型调用失败/未接入"，绝不伪装成模型结果。

### 前端（HarmonyOS）

1. DevEco Studio 打开 `03-演示文件与源代码/app/`
2. `File > Project Structure > 签名配置` → **取消勾选「自动生成签名文件」**
3. 选 `entry` 模块运行到模拟器 / 真机

### 一键自检（答辩前 30 秒）

```bash
python 03-演示文件与源代码/integration/run_liantiao5.py    # 契约 + 单测 + 95 项 HTTP + 归档
```

### 联调地址（最常见坑）

| 环境 | baseUrl |
|---|---|
| 本机浏览器 | `http://127.0.0.1:5000` |
| **HarmonyOS 模拟器** | **`http://10.0.2.2:5000`** |
| 真机（同一 WiFi） | `http://<开发机局域网IP>:5000` |

> 模拟器默认已是 `10.0.2.2`；App 内「工具 → 接口环境」页可直接改并持久化。

### 未能验证的部分（如实声明）

以下 3 项需 **HarmonyOS NEXT 真机**，本团队不具备该环境：

| 项 | 状态 |
|---|---|
| 华为账号一键登录 | 全部可离线核实的配置已逐项对齐（包名 / Client ID / 签名指纹 / 能力开通 / Profile / HAP 签名有效性 / 代码调用链），**缺真机做端到端联调** |
| 小艺口令 | 意图框架已注册，**缺真机** |
| 分布式跨设备数据流动 | 会话建立已双端验证；数据流动的观测量测需两台 NEXT 真机同局域网 |

**技术原因**（非配置问题）：本团队唯一真机为 HarmonyOS 4.2（基于 AOSP，
调试桥为 ADB），而本项目基于 API 24（HarmonyOS 6.x，调试桥为 HDB），
平台不可互通 —— 实测 `hdc list targets` 为空、Windows 仅识别到
`MI_00/MI_01/MI_02` 三个接口，无 HDC/HDB 接口。

模拟器侧：每台实例是独立 QEMU NAT 沙箱，双实例 eth0 IP 与 MAC 完全相同、
互 ping 100% 丢包，无网络路径可组网。

> 完整说明见 `项目文档/29-真机测试不必要性说明.md`。

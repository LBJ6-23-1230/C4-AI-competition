# 知学 Mate 小样本体验执行表 V1.0

> 目标：验证首次体验者能否在无口头指导的情况下理解 Agent 状态，并完成“42 → 58 → Plan V2”核心链。
> 版本要求：使用同一份已签名 debug HAP；每位体验者开始前重置 Fixture 演示数据。

## 1. 统一体验任务

只向体验者提供下面一句话，不解释页面路径：

> 请使用知学 Mate 找到当前最需要补强的知识点，完成一次诊断练习，并确认系统是否根据结果调整了学习计划。

完成标准：体验者能独立找到二叉树后序遍历 mastery 42，完成三道题，看到 67%、42 → 58、Plan V2，并能说出计划变化原因。

## 2. 观察记录规则

- 不提示操作，除非体验者连续 60 秒无法继续；发生提示时记录具体提示内容。
- 记录总耗时、首次犹豫位置、误触路径、是否理解 Agent 当前状态及下一步。
- 体验结束后只问固定问题，避免诱导答案。
- 严重度：P0 为无法完成主链；P1 为需要提示才能完成；P2 为能完成但理解或操作明显受阻；P3 为文案和视觉微调。

## 7. 每轮体验前检查

- 安装包版本、SHA-256 和构建时间已记录。
- 数据源为离线 Fixture。
- Agent Trace 中执行“重置演示数据”。
- 初始画像为 V1、mastery 42、证据 0 条，当前计划为 Plan V1。
- 模拟器或真机网络、电量和屏幕常亮状态正常。
- 录屏或观察记录已获得体验者同意，不收集无关个人信息。

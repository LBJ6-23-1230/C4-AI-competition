# 知学 Mate 前端测试方案 V1.0

## 1. 目的

确认当前前端版本能稳定运行，且用户可以从聊天页进入“薄弱诊断、错题分析、学习计划、学习搭子”四条产品主线。

本方案分为两部分：

- **当前可执行测试**：主动切换到离线 Fixture，不依赖真实后端，返回结构与正式接口契约一致。
- **后端联调测试**：仓库内状态化契约演示服务可立即执行；真实 LLM、图片识别和生产评分仍需对应服务。

> 注意：二叉树后序遍历 42 → 58 → Plan V2 是比赛固定核心链。真实后端模式连接失败时必须显示明确错误，不得静默切换到 Fixture 或本地算法。

## 2. 测试前准备

1. 在 DevEco Studio 打开项目 `D:\project\zhixue_Mate`。
2. 确认环境变量 `DEVECO_SDK_HOME` 的值为：

   ```text
   D:\develop\DevEco Studio\sdk
   ```

3. 连接模拟器或调试设备。
4. 点击“运行”。应用首次进入“知学搭子”聊天页。
5. 打开“全部工具 → 数据源设置”，选择“使用离线 Fixture”。
6. 如需从头验证核心链，在 Agent Trace 中点击“重置演示数据”。
7. 点击右上角“新对话”，确保开始时只有欢迎消息。

可在已连接模拟器上执行完整自动化回归：

```powershell
.\tools\run_ohos_regression.ps1
.\tools\run_app_startup_smoke.ps1
.\tools\run_ui_navigation_smoke.ps1
.\tools\run_fixture_ui_flow.ps1
.\tools\run_local_feature_ui_flow.ps1
.\tools\run_focus_ui_flow.ps1
```

这些脚本会依次覆盖 32 项 Hypium 测试、启动与导航、Fixture 核心链与重置、错题/搭子交接，以及专注未完成结算闭环。UI 脚本会重置当前模拟器中的演示状态，请不要在执行期间手动点击。

## 3. 测试结果记录规则

每一项都记录为以下之一：

- `通过`：实际结果与预期一致。
- `失败`：不能完成步骤，或结果与预期不一致。
- `阻塞`：由于设备权限、后端未启动等外部原因无法判断。

发现问题时，请记录：测试编号、操作步骤、实际现象、截图、发生时间。

## 5. 后端联调测试

仓库内的状态化契约演示服务已经可以用于真实 HTTP 联调；真实 LLM、图片识别与生产评分算法仍需对应服务和账号后再验收。

| 编号 | 需要后端提供 | 前端验证动作 | 预期结果 |
| --- | --- | --- |
| I-01 | 聊天接口 `/api/agent/chat` | 发送“薄弱诊断” | 真实 Agent 回复和卡片正确显示 |
| I-02 | 学习画像接口 | 打开并刷新知识画像 | 目标、掌握度、证据通过真实 HTTP 返回，不走应用内 Fixture |
| I-03 | 当前学习计划接口 | 打开计划页 | 任务、优先级和调整原因通过真实 HTTP 返回 |
| I-04 | 错题识别/分析接口 | 上传真实图片 | 返回知识点、错误类型、补强建议 |
| I-05 | 通用练习题接口及 `exerciseSetId` 来源 | 从某个薄弱知识点进入练习 | 页面按后端返回的课程和知识点显示，不写死二叉树 |
| I-06 | Trace 与重置接口 | 查看 Agent 决策过程、执行重置 | 显示契约演示事件；重置后数据恢复初始状态 |

## 6. 测试通过标准

当前版本满足以下条件即可视为前端基础验收通过：

1. 可以构建、安装和运行。
2. 聊天页的四条主线均能出现正确卡片并跳转到对应页面。
3. 错题分析的模拟流程可完成，并能进入学习计划。
4. 页面返回、重置聊天、空消息限制等基础交互正常。
5. 固定核心链能展示 67%、42 → 58、Plan V2 和完整 Agent Trace。
6. 真实后端异常时不静默回退，输入、重试和错误提示均可用。

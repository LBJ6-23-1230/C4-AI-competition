# 无华为手机如何拿到 HAP 附加分 —— 行动方案

> 结论来源：《2026"中国高校计算机大赛―人工智能创意赛"鸿蒙赛道 竞赛规程》§2 作品提交规则、§3 作品评审规则
> 适用对象：全体队员（队长 / 前端 / 后端）
> 结论一句话：**比赛交的是文件，不是手机。没有华为手机不影响提交与评审；借来的手机"用完即还"完全可行。**

---

## 一、先把"手机到底卡在哪一步"讲清楚

手机上要做的事只有 4 件，它们对设备的依赖程度完全不同：

| # | 事项 | 是否必须真机 | 说明 |
|---|---|---|---|
| 1 | 写代码 / 编译 | ❌ 不需要 | 全部在电脑上完成 |
| 2 | **申请调试证书 `.cer`** | ❌ 不需要 | ✅ 已完成（`zhixue-debug-cert.cer`） |
| 3 | **申请调试 Profile `.p7b`** | ✅ **需要至少 1 台已注册设备** | Profile 内含设备 UDID 白名单，AGC 不允许"零设备"创建 |
| 4 | 生成 HAP 包 | ✅ 需要第 3 步的 `.p7b` | DevEco 手动签名需要 `.p12 + .p7b + .cer` 三件套 |
| 5 | 装到手机看效果 / 录屏 | ✅ 需要真机 | 只有 `.p7b` 白名单里的设备能装 |

**关键性质：第 3 步注册的设备 UDID 是永久白名单。** 借来的手机注册一次，之后把手机还掉，Profile 照样能下载、HAP 照样能编译、白名单照样有效。

## 二、官方规程怎么说（原文摘录，这是判分依据）

### 提交规则（§2）

> 4）演示 Demo：**应用赛题须提交实际可演示的 HAP 文件 / Agent 赛题需提供源代码文件** / 用户体验、操作系统智能赛题需提供演示系统。
>
> 备注：
> a) 以上材料，初赛阶段 1/2/3 为必选，4 为可选；**复赛阶段 1/2/3/4/5 为必选**；
> c) **Agent 赛题需提供的源代码文件含项目运行所需的所有工程文件**或"小艺开放平台"上的测试态 Agent。

**本作品属 Agent 创新方向 ⇒ 第 4 项的达标物是「源代码文件（含全部工程文件）」，HAP 不是达标物。**

### 评分规则（§3）

| 评分项目 | 分数 | 说明 |
|---|---|---|
| 创新性 | 50 | 鸿蒙技术创新性、产品创意、交互创新、技术创新 |
| 完备度 | 20 | 功能完备度、体验完整顺畅 |
| 前景评估 | 20 | 需求真实性、社会价值、可落地商业价值 |
| 规范性 | 10 | 文档规范性、内容表达清晰度、功能演示清晰度 |
| **附加评分** | **20** | **实际可演示的 HAP 文件/源代码文件/演示系统、作品上架，附加评分越高** |

> 两个重点：① 附加分那一行 **"源代码文件"本身就是加分项之一**，不是只有 HAP 才算；② 复赛与总决赛 **均为线上评审**，评审对象是**提交的文件**，规程全文未出现任何"设备核验""真机演示"环节。

## 三、路线选择（推荐 A+C 并行）

### 路线 A —— 借机注册一次，一劳永逸（推荐）

1. 借一台**华为手机**（HarmonyOS 5.0 及以上，版本越高越好；需支持"开发者模式 + USB 调试"）。
2. 手机连电脑 → `设置 → 关于手机 → 连续点击版本号` 开启开发者模式 → `开发者选项` 打开 **USB 调试**。
3. 电脑上 `hdc shell bm get -u`（或 DevEco `Device Manager` 里直接看）读出 **UDID**。
4. AGC → `证书、APP ID 和 Profile` → **设备** → 添加设备 → 填 UDID → 保存。
5. AGC → **Profile** → 添加 → 类型选「**调试**」→ 选 `知学Mate` 应用 + 调试证书 → 下载 `.p7b`。
6. DevEco 手动签名三件套：`.p12`（已有 `E:\zhixue-signing\zhixue-debug.p12`）+ `.p7b`（第 5 步）+ `.cer`（已有 `zhixue-debug-cert.cer`）。
7. **把手机还给同学。** 之后 Profile 与 HAP 的产出不再依赖这台手机。

> ⚠️ **强烈建议：一次性把所有能借到的华为手机 UDID 都注册进去。** 一个应用最多 100 个 Profile、可绑定多台设备；多注册几台 = 后面录视频、演示、现场答辩时"任何一台都能装"，不会因为某一台不在手上而卡住。

### 路线 B —— 全程不碰手机，只产出「发布签名 HAP」

- AGC 申请 **发布证书 + 发布 Profile**。**发布 Profile 不绑定设备**（调试 Profile 才绑定），申请条件只有：已创建应用 + 已申请发布证书 + 账号具备"访问发布类Profile"权限。
- 用它签名可在纯电脑环境产出 `entry-default-signed.hap` 并放进提交 zip。
- ⚠️ **代价（重要）**：官方明确"**发布证书无法调试安装**"——发布签名包**不能侧载装到手机上**。所以路线 B 能拿到"HAP 文件"这个形式，但拿不到"在手机上跑起来"的证据。

### 路线 C —— 端侧算力之外，桌面/模拟器补齐

- 若你后来把 Windows 家庭版 Hyper-V 打通，本地模拟器可跑（系统镜像已下载：`HarmonyOS-6.1.1\{phone_all_x86, tablet_x86, pc_all_x86}`）。
- **但要注意**：模拟器 UDID 是否被 AGC 接受为"调试设备"未经验证，不要把它当唯一依赖。

### ✅ 推荐组合：**A + C**；B 作为兜底

A 拿到"能装能跑"的 HAP 与真机证据，C 提供备用演示环境，B 保证即使 A 失败也至少有一个签名 HAP 文件进包。

## 四、"借来手机 → 还回去 → 提交"到底行不行？

**行。** 分阶段看：

| 时间点 | 需要手机吗 | 说明 |
|---|---|---|
| 现在（配置签名链） | ✅ 借 1 次，约 30 分钟 | 只为读 UDID 建 Profile，读完即还 |
| 平时开发 / 编译 / pytest | ❌ | 纯电脑 |
| 打包 zip、写文档 | ❌ | 纯电脑 |
| **录 5 分钟演示视频** | ✅ **需要** | 视频要拍真机操作，建议在这段时间把手机借到手 |
| 提交（9/30 24:00 前） | ❌ | 只上传 3 个文件，平台不会核验设备 |
| 全国总决赛（11 月，线下） | ✅ | 现场答辩演示，那时需再借或自备 |

> 也就是说：**"借来手机拿到 HAP 再还回去"这个思路完全成立**，只要把「录视频」和「决赛演示」这两件事安排在有手机的时间窗里。

## 五、真正要盯的不是手机，而是这 3 件事

| 优先级 | 事项 | 负责 | 为什么 |
|---|---|---|---|
| 🔴 P0 | 借到任意一台华为手机，注册 UDID + 建调试 Profile | 队长/前端 | 这是整条签名链唯一的硬阻塞点 |
| 🔴 P0 | 服务卡片 `hasInsightIntent: true` 产物验证 | 前端 | 复赛创新性 50 分的主战场 |
| 🟠 P1 | 把「源代码 zip」按规程命名并自查 | 队长 | `03-作品名称+参赛队伍名称.zip`，Agent 方向的**达标物** |
| 🟠 P1 | 录音/录屏素材提前攒，手机到手当天就录 | 全员 | 手机是"限时资源"，不要等 |

## 八、给队长的一句话结论

> **不必为"没有华为手机"焦虑，也不必为"借的手机要还"焦虑。**
> 比赛交的是 3 个文件，全程线上评审，没有任何设备核验环节；
> Agent 方向的达标物本来就是**源代码**，HAP 只影响 20 分附加分。
> 借一次手机（约 30 分钟）注册 UDID 建好 Profile，**之后手机可以还回去**，编译 HAP 不再需要它。
> 唯一要重新用到手机的时点是**录演示视频**和**11 月决赛现场**——把这两件事排进有手机的时间窗即可。

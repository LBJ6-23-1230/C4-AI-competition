## 已知环境问题

Hvigor 的 `SignHap` 仍因本机无法解析项目已有 `.p12` 的加密参数而失败：

`parseAlgParameters failed: ObjectIdentifier() -- data isn't an object ID (tag = 48)`

这是现有签名材料/本机口令环境问题，发生在 ArkTS 编译、资源编译、打包检查全部完成之后。按项目《签名材料交接说明》，需要在 DevEco 的 Signing Configs 中用原始明文口令重新应用签名材料，或使用明文口令调用 `hap-sign-tool`。本轮没有明文口令，未改动签名身份。

最新 HAP 安装成功后模拟器进程异常退出；后续实例只停留在约 59 MB 的启动进程，HDC 未重新连接，因此本轮无法完成最新界面的逐项点击截图。代码编译、接口行为、自动化测试和设备安装均已验证。
